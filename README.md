# Tesla and GameStop Stock and Revenue Analysis

## Overview

This project extracts, cleans, and visualizes stock price and revenue data for Tesla and GameStop. It demonstrates a complete data acquisition and visualization workflow using financial APIs, web scraping, data wrangling, and interactive plotting.

## Objectives

- Extract stock price data using yfinance
- Scrape quarterly revenue data from HTML tables
- Clean financial revenue data
- Visualize historical stock and revenue trends
- Build a simple financial data dashboard

## Methods

The workflow includes:

- Data extraction with yfinance
- Web scraping with requests and BeautifulSoup
- Data cleaning with pandas
- Time-series visualization with Plotly

- requests

- Plotly
